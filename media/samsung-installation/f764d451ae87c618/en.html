Install YAIP on your Samsung TV

Video transcript. Illustrated guide with AI-generated narration.

Back to the installation guide

Start on your computer.

Start on your Windows computer or Mac. Open the YAIP website, choose Download, then Samsung. Open the Samsung setup guide. Keep it nearby so you can pause and follow each step.

On screen: Open yaip.duckdns.org → Download → Samsung.

Two kits. One TV.

Samsung requires test apps to be signed for each television. First, you will download a small kit that reads your TV’s unique ID. After registration, the bot will send a different kit that can install YAIP on your TV.

On screen: First: read your TV ID. Later: install your signed kit.

Download the TV ID kit.

In the guide, click Download Samsung TV ID kit. Save the ZIP on your computer. If you are reading on your phone, open the guide on the computer before continuing.

On screen: Click Download Samsung TV ID kit (.zip).

On Windows: extract the ZIP.

On Windows, open Downloads. Right-click the ZIP, choose Extract All, then Extract. Open the new folder. Do not run the installer from inside the ZIP.

On screen: Downloads → right-click the ZIP → Extract All → Extract.

On Mac: unpack the ZIP.

On Mac, open Downloads and double-click the ZIP to unpack it. Then open the new folder. If your browser already unpacked the download, use that folder.

On screen: Double-click the ZIP, then open the new folder.

Keep every file together.

Keep all the extracted files together, including the folder named files. Next, open the installer for your computer. You do not need Samsung’s developer tools or a developer account.

On screen: Keep the files folder beside the two installers.

On Windows: open the installer.

If you use Windows, double-click the Windows installer highlighted on screen. Its filename is Install on Windows, ending in dot C M D.

On screen: Double-click Install on Windows.cmd.

On Mac: open the installer.

If you use Mac, double-click Install on Mac dot command. Choose only the installer that matches your computer.

On screen: Double-click Install on Mac.command.

If Windows blocks this kit…

If Windows blocks this official YAIP kit, choose More info, then Run anyway if offered. If asked, allow Samsung’s connection tool on your private home network. Do not turn off Windows protection or the firewall.

On screen: For this YAIP download: More info → Run anyway, if offered.

If Mac blocks this kit…

If Mac blocks the installer because its developer is unidentified, open System Settings, then Privacy and Security. Find the installer message, choose Open Anyway, and confirm. On Apple silicon, follow any Rosetta prompt. Never send your Mac password to the bot.

On screen: System Settings → Privacy & Security → Open Anyway → Open.

Use the same home network.

Make sure the computer and TV are on the same home network, with internet access. Avoid guest Wi-Fi. A VPN may prevent the devices from seeing each other.

On screen: Connect the computer and TV to the same home network.

Find your computer’s IP.

A text window opens. This is the installer. Find the line showing this computer’s IP address and leave the window open. You will enter that computer address on the television next.

On screen: Leave the installer open at This computer's IP address.

On the TV: open Apps.

On the TV, press Home and open Apps. On some newer models, open App Settings inside Apps. Menu names can vary, so use the written guide if your screen looks different.

On screen: Home → Apps. Newer model? Open App Settings if needed.

Enter 12345.

Enter one, two, three, four, five using the remote’s number buttons or its on-screen number keypad. The Developer Mode window should appear.

On screen: Use the remote’s number keys or the on-screen number keypad.

Turn on Developer Mode.

In that window, turn Developer mode on. This is a built-in Samsung setting. You do not need to install a separate Developer Mode app.

On screen: Change Developer mode to ON.

Enter the computer address.

In Host PC IP, enter the computer’s IP address shown by the installer, then confirm. Use your own computer’s address, not the example in this video. Do not enter the TV’s address in this field.

On screen: Host PC IP = the computer IP from the installer.

Restart the television.

Restart the television as described in the kit. Switch it off, unplug it for thirty seconds, then reconnect it and turn it on. Keep Developer Mode enabled.

On screen: Switch off → unplug for 30 seconds → reconnect and turn on.

Now find the TV’s IP.

Find the TV’s own IP address in its network settings, under Network Status and IP Settings. This is a different address from the computer’s. The computer address goes on the TV; the TV address goes into the installer.

On screen: Settings → Network → Network Status → IP Settings.

Read your TV’s ID.

Return to the installer on your computer. When it asks for the TV IP address, type the address from your television, including the dots, and press Enter. The installer will read the TV’s ID.

On screen: Back on the computer: enter the TV IP, then press Enter.

Keep the complete TV ID.

Wait for Your TV ID. The complete ID is copied to the clipboard and saved in the text file shown on screen, inside the extracted folder. Keep any version prefix. Use this ID, not a serial number or MAC address. This first kit does not install YAIP.

On screen: Copy Your TV ID, also saved in MY TV ID.txt.

Open the support bot.

Back in the guide, choose Register my TV on Telegram. Open the bot and press Start if asked, or send the slash Samsung command shown on screen.

On screen: Use Register my TV on Telegram in the guide.

Paste the ID. Wait for confirmation.

Paste only your complete TV ID and send it. Wait for the bot to confirm that it is saved. No password is needed. Samsung includes TV IDs in the downloadable test certificate and kit, while your Telegram account stays private.

On screen: Send only your complete TV ID.

Registration saved. Wait for your kit.

Your registration is now saved. The developer starts signing batches, so the install kit is not ready immediately and there is no fixed waiting time. Keep the bot chat available. You can check your status with the same command.

On screen: The developer prepares signing batches.

Your install kit is ready.

Later, the bot will tell you when a verified install kit includes your TV. Download the ZIP from that message on your computer. Use your own bot link, because another tester’s kit may not include your television.

On screen: Wait for the bot’s ready message, then use its download link.

Extract the new signed kit.

Extract this new ZIP into a new folder and keep all its files together. Read Read Me First, then open the Windows or Mac installer again. Make sure you are running the new signed kit, not the old ID kit.

On screen: Extract into a new folder. Open the correct Windows or Mac installer.

Let the kit install YAIP.

Keep Developer Mode on and check that Host PC IP still matches your computer. Enter the television’s current IP address in the installer. This kit includes your TV, so it transfers and installs YAIP. Leave the television on and wait for completion.

On screen: Check Host PC IP, then enter the TV’s current IP in the installer.

YAIP is on your TV.

YAIP should open on the TV. Later, open it from Apps and add your own playlist. YAIP is a free player and includes no content. For an update, run a newer kit supplied for your TV. Keep the existing app to preserve local profiles.

On screen: Open YAIP from Apps and add your own playlist.

Need help? Return to the guide.

If you get stuck, return to the written guide or ask the support bot. Tell it your TV model, computer system, the step and the error. Hide passwords and TV IDs in screenshots. Pause this video whenever you need more time.

On screen: Use the written guide or contact the Telegram support bot.
