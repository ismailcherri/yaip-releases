# Screenshots

Window captures of YAIP desktop on GNOME, used by the app's AppStream metainfo (Flathub, GNOME Software, KDE
Discover). The metainfo links them at a release tag, so these files are never changed in place: new screenshots are
added for a new tag.

They show YAIP's demo provider, which serves only Creative Commons films, and no real provider, channel or account.
YAIP itself comes with no content.
